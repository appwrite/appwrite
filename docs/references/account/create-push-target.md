Use this endpoint to register a device for push notifications. Provide a target ID (custom or generated using ID.unique()), a device identifier (usually a device token), and optionally specify which provider should send notifications to this target. The target is automatically linked to the current session and includes device information like brand and model. If the session already has a push target for that provider, its identifier is replaced rather than a second target created, so a device that rotates its token is never notified twice.
