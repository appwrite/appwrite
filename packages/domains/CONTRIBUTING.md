# Contributing

Utopia Domains is developed in the [utopia-php monorepo](https://github.com/utopia-php/monorepo). The `utopia-php/domains` repository is a read-only distribution mirror.

Open issues and pull requests against [`packages/domains`](https://github.com/utopia-php/monorepo/tree/main/packages/domains) in the monorepo. Follow the monorepo's [contribution guide](https://github.com/utopia-php/monorepo/blob/main/CONTRIBUTING.md) for setup, testing, and review requirements.
