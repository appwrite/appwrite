# Vibes-native changelog entries

Entries in this directory are **not** replaced when you run `bun run import:changelog`.

Use `src/content/changelog-local/entries/` for product updates that live only in vibes. Imported website changelog content remains in `src/content/changelog/`.

Store images under `public/images/changelog-local/` or reuse `public/images/blog-local/` covers so they are not overwritten when changelog images are re-imported from the website repo.
