# Vibes-native changelog entries

Use `src/content/changelog-local/entries/` for product updates that live only in vibes. Changelog content originally published on the website remains in `src/content/changelog/`.

Store images under `public/images/changelog-local/` or reuse `public/images/blog/` covers. Both are served from this repo; other `/images/` paths in changelog frontmatter resolve to the marketing site.
